# 📊 Análise de Cancelamento de Clientes

Este projeto realiza uma análise de cancelamento de clientes utilizando Python e Pandas.  
O objetivo é identificar padrões de comportamento que levam ao cancelamento do serviço e propor ações para reduzir o churn.

---

# 🚀 Tecnologias utilizadas

- Python
- Pandas
- Plotly Express
